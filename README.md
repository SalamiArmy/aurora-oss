# Sunswarm (working title)

An open-source real-time strategy game: own suns, grow them, send swarms of ships to capture neutral suns and
crush rival factions. Two to four factions per level, special objects (orbiting and fragile suns, wormholes,
supernovas, gamma rays, terrain zones) and an AI opponent. Written in Rust; the simulation is headless and
deterministic.

> **Status: early.** The repository currently holds the content and documentation. The game core is being written
> under a clean-room process; see below.

## What's here
| Path | What |
|---|---|
| `levels/` | 32 levels in 7 constellations, generated by `tools/gen_levels.py` (see `levels/levels.txt`) |
| `assets/` | Synthesised sound effects, textures and meshes, generated by `tools/gen_oss_assets.py` |
| `crates/au2-music` | A small synthesiser and procedural songs |
| `cleanroom/public/RULES.md` | Observable gameplay rules (what the game core must do) |
| `cleanroom/public/MAPFORMAT.md` | The plain-text level format |

Everything here was written or generated from scratch. Regenerate the levels and assets with:

```
python tools/gen_levels.py levels
python tools/gen_oss_assets.py assets        # needs numpy and soundfile
```

## Roadmap
1. Simulation core written from `RULES.md` (deterministic, 60 Hz fixed step).
2. Map loader written from `MAPFORMAT.md`.
3. AI that finishes every shipped level.
4. Desktop and Android front ends.
